Secchi Servicios

A custom desktop application designed to streamline client management and service billing. SecchiServicios focuses on organizing client information and generating service receipts in PDF format, with a structured and user-friendly interface.

Built with C# and .NET using Avalonia UI, the application follows the MVVM architectural pattern and uses SQLite for data persistence. The project aims to simplify administrative workflows and provide a practical solution tailored to the client's needs.

Infinito

A desktop application developed to manage inventory, sales, customers, and suppliers in a centralized system. Infinito helps organize product information, track stock levels, and manage essential business operations through an intuitive graphical interface.

Developed with C# and .NET using Avalonia UI and the MVVM architectural pattern, the application uses Entity Framework Core and SQLite for data persistence. The project demonstrates the application of object-oriented programming, dependency injection, and repository-based data access in a practical business management solution.

C# .NET Avalonia UI Entity Framework Core Inventory Managment CRUD

Python Automation Script

A Python automation script designed to streamline monthly payment reminders for recurring services. The script retrieves customer and due-date information from Google Sheets and integrates with Evolution API to send WhatsApp reminders before payment deadlines.

The goal is to reduce manual follow-up, improve payment tracking, and help prevent service interruptions or additional reconnection charges caused by late payments. This project combines spreadsheet data management, API integration, and workflow automation to solve a practical business problem.

Python API Integration Google Sheets Docker Evolution API
